A /

Quorum overlap

When W + R > N, the write set and read set must share at least one node, so a quorum read is guaranteed to see the newest committed write — strong consistency without a full broadcast.

B /

Eventual consistency

Drop the quorum and reads hit a single replica. Followers still converge as replication catches up, but a read can return a stale value in the window before it does.

C /

Last-write-wins

Every write carries a monotonic version from the leader. Replicas apply a value only if its version is newer, so re-ordered or replayed messages never move a record backwards.

D /

Partition tolerance

Partition a node and it stops acknowledging. Writes still commit if the remaining replicas satisfy W; the partitioned node replays the log and rejoins in sync on reset.

04 / DISTRIBUTED PROTOCOLWHY THE DATA HOLDS

THE SIGNAL UNDER THE UI

Trust is
a system.

The backend is a teaching-grade distributed system with the right production instincts: failure detection, logical time, optimistic versioning, and exactly-once dispensing semantics.

A /

Bully election

The highest-priority reachable node becomes coordinator when a failure is detected.

B /

Lamport clocks

Every routed request carries logical time across client, router, and branch boundaries.

C /

Idempotent ledger

A unique dispensing key protects the same logical action from being applied twice.

D /

Vector-clock stock

Inventory rows retain branch-local causality so concurrent updates can be surfaced as conflicts.

          A /

          Quorum overlap

          When W + R > N, the write set and read set must share at least one node, so a quorum read is guaranteed to see the newest committed write — strong consistency without a full broadcast.

          B /

          Eventual consistency

          Drop the quorum and reads hit a single replica. Followers still converge as replication catches up, but a read can return a stale value in the window before it does.

          C /

          Last-write-wins

          Every write carries a monotonic version from the leader. Replicas apply a value only if its version is newer, so re-ordered or replayed messages never move a record backwards.

          D /

          Partition tolerance

          Partition a node and it stops acknowledging. Writes still commit if the remaining replicas satisfy W; the partitioned node replays the log and rejoins in sync on reset.

            A load balancer answers one question, over and over: of the backends that are healthy right now, which should serve the request in my hand? Seven algorithms answer it differently, and the difference only shows under load.

            C / THE BACKEND POOLSIX BRANCH NODES · LIVE HEALTH

            Crash a node and dispatch a burst: it keeps taking requests until three of them fail, its breaker opens, and the rest of the burst goes to the other five. Six seconds later the breaker goes half-open and one probe decides whether it rejoins.

            D / WHAT THE RUN MEASUREDDISTRIBUTION · LATENCY · FAIRNESS

            Perfect fairness and good latency are different goals, and some algorithms trade one away for the other on purpose. Least response time will happily send most of a burst to the quickest node — that is the bet, not a bug.

            F / HOW THE BALANCER WORKSHEALTH · BREAKER · DISPATCH
            1. 01 / PROBE

              Health check before every burst

              Each backend's RMI registry port gets a TCP connect with a 250 ms timeout. Answering means the request will travel over RMI; not answering means the gateway serves it locally and says so in the trace.

            2. 02 / SELECT

              The algorithm picks from the healthy set

              Only backends whose circuit breaker is closed are offered. The chosen rule applies to that set, and the reason it produces is carried through to the trace.

            3. 03 / DISPATCH

              The request is really executed

              Over RMI when the node is listening, otherwise against PostgreSQL here — including the SHA-256 integrity pass each node runs over its own branch's prescriptions. Service time is measured around that work.

            4. 04 / ACCOUNT

              Every result updates the pool

              Success clears the failure streak and updates the node's exponentially weighted mean latency, ewma = 0.8·ewma + 0.2·sample. Failure increments the streak and drops the cached RMI stub.

            5. 05 / BREAK

              Three failures open the circuit

              A crashed node keeps being offered work until three failures are actually observed — that detection gap is real, and hiding it would make the breaker decorative. The open breaker then removes it for six seconds before a half-open probe decides.

            HEALTH STATES
            HEALTHY_RMI answering on its registry port; requests travel over RMI
            HEALTHY_LOCAL in the pool, but the node process is not up, so the gateway serves it
            FAILING crashed, but still in the pool — not enough failures observed yet
            PROBING breaker half-open; one request decides whether it rejoins
            CIRCUIT_OPEN three consecutive failures; out of the pool for six seconds

            THE SIGNAL UNDER THE UI

            Trust is
            a system.

            The backend is a teaching-grade distributed system with the right production instincts: failure detection, logical time, optimistic versioning, and exactly-once dispensing semantics.

            A /

            Bully election

            The highest-priority reachable node becomes coordinator when a failure is detected.

            B /

            Lamport clocks

            Every routed request carries logical time across client, router, and branch boundaries.

            C /

            Idempotent ledger

            A unique dispensing key protects the same logical action from being applied twice.

            D /

            Vector-clock stock

            Inventory rows retain branch-local causality so concurrent updates can be surfaced as conflicts.
